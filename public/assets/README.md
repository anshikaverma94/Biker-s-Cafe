# Images go here

Drop your image files directly into this folder (`public/assets/`). The page already
references these exact filenames — just save your images with these names and they'll
show up automatically, no code changes needed:

| Filename              | Used for                                   |
|-----------------------|---------------------------------------------|
| `bikers-cafe-logo.png`| Header logo, footer logo, checkout modal, ticket |
| `garba-hero.jpg`      | Big hero photo (garba circle) on the homepage |

If you want to add more photos (e.g. for the "Three hours of taali, dhol and chai"
section), save them here too and tell me the filenames — I'll wire them into the page.
